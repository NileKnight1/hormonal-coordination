# Hormonal Coordination
` A game made in Godot `

There are 5 levels:
## Pancreas
### Gameplay
An event happens each some seconds changing "glucose" level, either increasing or decreasing it.
You have two hormones to achieve homestasis of glucose, "Insulin" and "Glucagon", insulin decreases the glucose level, while glucagon increases it.
### Difficulty
Difficulty increases with time, which decreases time between each event and other.
### Scoring
There are three zones of scoring:
extreme: -3/sec
med: +1/sec
perfect: +2/sec
### Death
If glucose level reaches 60 or 300 you die.
