# Hormonal Coordination
` A game made in Godot `

## There are 5 levels:
## Pancreas
### Gameplay
An event happens each some seconds changing "glucose" level, either increasing or decreasing it.
You have two hormones to achieve homestasis of glucose, "Insulin" and "Glucagon", insulin decreases the glucose level, while glucagon increases it.
### Difficulty
Difficulty increases with time, which decreases time between each event and other.
### Scoring
There are three zones of scoring:
extreme: -3/sec
med: +1/sec
perfect: +2/sec
### Death
If glucose level reaches 60 or 300 you die.

## Thyroid
### Gameplay
Same as pancreas but two different hormones
### Death
If caclium level reaches 6 or 12.5 you die.

## Adrenal
### Gameplay
An event happens each some seconds, you have the ability whether secrete adrenaline or not.
### Scoring
There are four types of events:
  1st: extreme ones, gives 3 points if secreted and -1 health if not.
  2nd: needs adrenaline but not crucial, gives 1 point if secreted and -1 point if not
  3rd: inverse of the 2nd
  4th: inverse of the 1st
### Death
If health reaches 0 you die.

## Pituitary
### Gameplay
An event happens each some seconds, you have to guess which hormone is the right one between the 4 ones.
### Scoring
-1 health: if you don't choose or choose a wrong one.
+3 points: if you choose correct very fast.
+2 points: if you choose correct fast without very.
+1 point: if you choose correct at last seconds.
### Death
If health reaches 0 you die.

## General 
You move between Thyroid/Pituitary/Pancreas 
### Gameplay
An event happens each some seconds, it affect some values of 6 stats, glucose, calcium, water levels and heart rate, blood pressure and BMR.
### Scoring 
  It's simple here, just  elapsed time.
  Medium: time is doubled.
  Hard: time is tripled.
### Death
Easy: if 3 values reach extreme, you die.
Medium: if 2 values reach extreme, you die.
Hard: if 1 value reaches extreme you die.
